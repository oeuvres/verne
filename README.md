# Jules Verne

Cette collection de textes TEI normalisés vise à proposer un nombre substantiel de romans attribués à l’auteur. Ces fichiers ont été réunis à fin d’expériences de textométrie, ce n’est pas une édition complète et relue. Les textes ne sont pas originaux mais repris de différents sites de livres électroniques libres et gratuits.

Les textes de datation ou d’attribution douteuses sont renvoyé dans le dossier misc/
